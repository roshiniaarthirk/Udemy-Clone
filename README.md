🎓 Udemy Clone – Responsive Frontend Project
📖 Overview

This project is a responsive Udemy Clone developed using HTML5 and CSS3. It replicates the core layout of an online learning platform, including navigation, course listings, and structured UI components. The focus of this project is on layout design, responsiveness, and clean user interface implementation.

✨ Features

Responsive navigation bar

Course categories section

Reusable course cards with image, title, rating, and price

Structured layout using Flexbox

Mobile-friendly design using media queries

🛠️ Tech Stack

HTML5

CSS3

Flexbox

Media Queries
